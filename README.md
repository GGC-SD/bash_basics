# Collaborative Bash & Git Exercises

**ITEC 3860/3870 coursework in shell scripting, branches, merges, and conflict resolution.**

This repository contains shared educational material and contributions from multiple students. It retains the original teaching examples and [license](LICENSE). The source collection is not solely my original work.

## Try the greeting script

```bash
bash -n "Joshua Wilson/joshua.sh"
bash "Joshua Wilson/joshua.sh"
```

Expected greeting:

```text
Welcome Joshua Wilson
```

Use Bash on Linux, macOS, or a suitable shell environment. Review other scripts individually before running them. They are teaching examples, and some demonstrate repeated or system-specific commands.
